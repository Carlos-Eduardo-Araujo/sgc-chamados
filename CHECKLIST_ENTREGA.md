## AÇÃO NECESSÁRIA PELO ALUNO antes de entregar
- [ ] Preencher nome da disciplina, professor, nomes completos e RAs.
- [ ] Criar repositório público no GitHub e substituir `[LINK DO GITHUB]`.
- [ ] Criar/proteger `main`, criar `develop` e trabalhar por `feature/*`.
- [ ] Criar GitHub Project e Issues a partir do backlog do README.
- [ ] Fazer commits reais em feature branches.
- [ ] Abrir Pull Requests e obter comentário/aprovação de outro integrante antes do merge.
- [ ] Usar de fato o agente escolhido e capturar evidência real de configuração/uso.
- [ ] Executar `docker compose build` e `docker compose up api` em máquina com Docker.
- [ ] Executar `docker compose run --rm tests` e capturar print do resultado.
- [ ] Fazer push e confirmar GitHub Actions verde; capturar print da execução.
- [ ] Inserir prints reais no PDF final.
- [ ] Atualizar o PDF com link do GitHub, integrantes e evidências.
- [ ] Cada integrante deve submeter o PDF no Moodle conforme o enunciado.
